# PHLife v0.2
A much richer Port Harcourt multiplayer life-sim vertical slice.

Included:
- original Port Harcourt world map with 20 destinations
- draggable/zoomable map
- rotatable home scene
- character/background generator
- five origins
- expanded needs
- PHPhone with 12 app concepts
- PHJobs / PHProperty / PHCampus / PHChat
- Supabase Realtime presence + Broadcast chat/invites
- UniPort, RSU and IAUE
- PWA files

Production roadmap: authoritative server actions/economy, permanent accounts, persistent homes, true 2.5D movement, vehicles, businesses, moderation, relationships/families, rich list, elections, events, and scalable rooms.


Deployment package: all visual SVG artwork is embedded in index.html, so only these files need to be uploaded.
